⚙ Firebase Setup Required
This app isn't connected to Firebase yet. Paste your prettydollcrm Web API Key below (Firebase Console → Project Settings → General → Web API Key) and it will be saved on this device.
Finance access is protected by Firebase Authentication. After you have signed in once online, you can also sign in without internet on this PC (valid for 30 days after your last online sign-in). Everyone must enter their full name to sign in. The first registered finance user becomes the Owner; the Owner assigns Finance Manager, Accountant or Staff access from Settings.
